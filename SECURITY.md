# Security policy

Report suspected vulnerabilities through
[GitHub's private vulnerability reporting form](https://github.com/oraclevs/nib_motion/security/advisories/new).
Sign in to GitHub to use the form. Do not include exploit details, credentials,
or private application data in a public issue.

Include the affected NibMotion and Flutter versions, platform and renderer,
reproduction steps, and the impact you observed. A small reproduction without
real user data helps us investigate.

Security fixes target the latest published release. Older versions do not have
a separate maintenance schedule. We will coordinate disclosure through the
private report; we cannot promise a response or fix deadline.

For ordinary bugs and usage questions, see [support](SUPPORT.md).
