# Getting help

Start with the [guides](doc/README.md), the
[example app](example/README.md), and the
[API reference](https://pub.dev/documentation/nib_motion/latest/).

Search [existing issues](https://github.com/oraclevs/nib_motion/issues) before
opening a report. For a bug, use the bug-report form and include a small runnable
reproduction, `flutter --version`, the package version, and your platform.
Rendering problems also need the renderer, device or browser, and a screenshot
or recording when possible. Remove credentials and private data from logs.

For a usage question, open an issue with the question, the relevant code, and
what you have tried. For a feature idea, use the feature-request form and explain
the interface you want to build.

Support is community based; there is no guaranteed response time. Security
reports belong in the [private reporting channel](SECURITY.md).
