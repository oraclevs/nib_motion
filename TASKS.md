# Project work

Use [GitHub issues](https://github.com/oraclevs/nib_motion/issues) for bug reports
and proposed features, and [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution
workflow.

The [2026-11-02 launch audit](doc/maintainers/launch-audit.md) separates tested
capabilities, known limits, experiments, and follow-up work. Publication is
tracked in the [release checklist](doc/maintainers/release.md); no task list
entry authorizes publishing a version.

The previous runtime-development log is preserved in
[the historical archive](doc/maintainers/history/runtime-development-2026-10-14.md).
Its version numbers, test counts, comparisons, and release instructions are
historical snapshots.
